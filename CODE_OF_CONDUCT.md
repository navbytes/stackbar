# Code of conduct

Stackbar follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussion about the work.
Harassment, personal attacks and discriminatory language aren't welcome in
issues, pull requests or anywhere else the project lives.

Report conduct problems privately to the maintainer through
[GitHub](https://github.com/navbytes). Reports are kept confidential.
